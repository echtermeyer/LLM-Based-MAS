% ------------------------------------------------------------
% Robustness:
%   - New critical system prompt experiment (NB 029): anti-
%     conformity instruction yields faster fc convergence
%     (-1 to -1.5 rounds, Holm-sig in 3/6 configs) but no
%     accuracy change and no bistability reduction. Gains are
%     dynamical not epistemic. SR flat (0/6 Holm-sig).
%     Interpretation: the prompt change modulates speed of
%     entrenchment but not the underlying motif structure.
%
% Limitations:
%   - Phenomenological, not causal: all four motif detectors
%     detect signatures, not certified attractors/causes.
%     Perturbation experiments needed for causal claims.
%   - Single model (Mistral-Medium), two benchmarks, N=4:
%     generalizability to other models, larger N, other tasks
%     is not guaranteed.
%   - SR null model survivorship bias: downward confidence
%     drift censoring may inflate p_SR above 0.5 baseline.
%     Results conservative but not bias-free.

%     (longer runs have more opportunity for slope to develop).
%   - Linguistic scorer not independent (same model as agents).

% Practical takeaways for practitioners building MAD systems:
%
%   - Use star topology if worst-case efficiency is a concern
%     (no genuine limit cycles in fc; star can trap debates).
%   - fc produces stronger SR and faster convergence -- prefer
%     when speed matters and initial conditions are reliable.
%   - A hard round cap is necessary with star topology; reaching
%     T should be treated as an explicit unresolved-output signal.
%   - Memory window W is not a reliable tuning knob for accuracy
%     or SR; its effect on dominance (W entrenches hub in star)
%     is the clearest actionable signal.
%   - Promoting initial vote diversity (seeded initialization)
%     is the largest lever for slowing SR and extending debate.
%   - Linguistically heterogeneous agent styles (diverse anchoring
%     and dialogic behavior) correlate with faster resolution --
%     consider prompt diversity as a design axis.

%     debate provides large accuracy gains (+24 pp) but motifs
