## 1. CRITICAL — Linguistic section computed on a deleted dataset (22 mismatches)

`sec:results:linguistic` (`06_results.tex` ~L1398–1458, incl. `tab:ling:diversity`) reports
diversity↔MAS correlations computed against `results/mas/final_dataset` (the **old-prompt** corpus,
since deleted). Recomputed on the current `final_dataset_new_system`, the correlations are
systematically **weaker** and several flip significance. Notebook `10_linguistic`.

Representative (tex → notebook):
- conviction diversity × Rounds: **−0.55*** → −0.39*** ; anchoring −0.54 → −0.37 ; dialogic −0.51 → −0.30
- "all p<10⁻¹⁰ (pooled diversity vs rounds)" → dialogic is p=3.5e-10 (fails the 10⁻¹⁰ claim)
- conviction × Acc(GPQA): +0.11 (ns) → **+0.20*** ; conviction × Acc(HB): −0.24*** → −0.11 (ns)
- anchoring × Acc(GPQA): +0.18** → +0.12 (ns) ; anchoring × Acc(HB): −0.16* → −0.12 (ns)
- within-dataset (GPQA anchoring −0.41 → −0.067 ns; GPQA dialogic −0.32 → −0.079 ns; HB dialogic
  −0.38 → −0.011 ns; HB anchoring −0.35 → −0.152), and "all p<10⁻³" no longer holds
- ch7 re-quote "diversity vs rounds ρ≈−0.5" overstates — max magnitude is −0.39

Linguistic-only numbers are **unaffected and MATCH**: 420 cells, NLI 221 files, system-level means
(conviction 3.55/3.30, dialogic 3.01/2.51), conviction_std × N_eff.

**Decision needed:** either (a) update `tab:ling:diversity` + prose to the new-dataset values that
`10_linguistic` now computes (the directional story — anchoring/conviction diversity → fewer rounds
— survives, just weaker), or (b) re-score linguistics on the exact corpus the table was built from
(if it can be reconstructed). Recommend (a).
